# 국가별 기본 양식·용어 대조 결과

확인일: 2026-10-03 · 양식 버전: `2026-10-03.3`

이 문서는 기본 양식 대조 기록이다. 국가별 세부 요건 전체 완료를 의미하지 않는다. **② 세부 요건·③ 전문용어 검수**의 작업별 후속 결과와 미완료 항목은 [작업별 검수 기록](regional-task-review.md)을 따른다. **⑤는 실제 계정의 저장·접근권한 검증**이며 이 자료 검수와 별도다.

## 이번 검수의 범위와 결과

현재 지원하는 14개국·18개 국가/지역 설정 전체를 대상으로, 공식 기관의 위험성평가 안내·서식 예시·작업허가 안내와 현재 기본 양식을 대조했다. 문서 명칭뿐 아니라 평가일, 근로자 참여, 전달 기록, 조치 확인, 재검토, 허가 역할 구분을 수정했다. 실측값·서명·평가일·현장 확인은 재사용 가능한 표준값으로 저장하지 않는다.

아래의 **의무**는 인용 규정의 적용 범위에서 요구하는 사항, **조건부**는 해당 작업·조직 조건을 충족할 때 적용되는 사항, **안내**는 공식 실무 지침을 뜻한다. 입력란을 제공하는 것과 그 의무가 실제 현장에서 이행됐다는 판단은 별개다. 모든 입력란을 일괄 필수로 만들거나, 입력 여부만으로 법적 적합성을 판정하지 않는다. 수기 작성용 출력도 지원한다.

국가를 선택하는 것만으로 모든 업종의 법정 문서를 결정할 수는 없다. 아래에서 명시한 기본 양식 범위에 대한 대조 결과이며, 업종별 허가·측정 기준을 모두 자동 판정하는 기능은 아니다.

## 공통 작업허가서 수정

[HSE PTW 안내](https://www.hse.gov.uk/humanfactors/topics/ptw.htm)와 [MOM PTW 안내](https://www.mom.gov.sg/workplace-safety-and-health/safety-and-health-management-systems/permit-to-work-systems)를 참고해 일반 허가 생애주기 기록을 보강했다. MOM 자료의 OPEC 산업 범위를 다른 모든 업종에 대한 법정 의무로 확대하지 않았다.

- 적용하는 허가서 양식·절차의 참조
- 신청자/작업 책임자, 현장 안전조치 확인자, 발행자, 작업팀 인수·확인의 별도 서명란
- 작업 중단, 재허가, 교대 인계 기록
- 기존 유효시간, 차단, 현장 측정, 비상대응, 종료·인계 기록 유지

역할 구분은 서식에 제공하는 기본 구조다. 국가별로 항상 네 명의 서로 다른 사람이 서명해야 한다는 규칙을 구현한 것은 아니다. 현장 절차에 따라 역할을 지정한다.

## 아직 자동화하지 않은 구체적인 판단

이 목록은 사용자에게 검수 작업을 넘기는 목록이 아니라, 후속 개발에서 조사할 범위다.

1. 자유 입력된 업종·작업명에서 특정 법령의 적용 대상을 결정하는 규칙. 현재는 사용자가 선택한 국가와 문서 종류를 기준으로 기본 양식을 구성한다.
2. 고소·밀폐공간·전기·화기 등의 별도 법정서식, 자격 요건, 측정 기준, 허가 유효시간. 이번 일반 PTW에 특정 업종의 숫자 기준을 무리하게 넣지 않았다.
3. 브라질 2026년 NR-35 개정 내용 및 러시아 분야별 규정의 최신 개정본을 반영한 전문 양식. 이전 러시아 782н 원문 페이지에는 2025년 말 종료 문구가 남아 있어 그 원문을 2026년 현행 기준으로 하드코딩하지 않았다.
4. 사업장 규모·도급 구조 등에 따라 달라지는 Québec 예방계획, 프랑스·이탈리아 조직 문서 전체 생성 기능. 현재는 관련 문서 참조와 조정 기록을 제공한다.
5. 실제 계정의 저장·공유·접근권한 시험. 이번 코드 변경은 기존 개인 저장 구조와 접근권한을 수정하지 않는다.

## 저장 및 호환성

새로 생성한 양식에만 새 버전을 적용한다. 기존 저장본 및 출력본은 변경하지 않는다. 공식 자료 대조 범위와 버전은 `regional.review`, 참고 출처는 `regional.sources`에 보존된다. `site-review-draft` 상태를 유지하고 법적 적합성 인증 배지를 생성하지 않는다. DB 마이그레이션은 없다.
