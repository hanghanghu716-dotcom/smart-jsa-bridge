# 퀘벡 화기: CSA 로그인 이후 원문 대조 — batch 30

확인일 2026-10-06. 기존 batch 28의 **CSA 로그인 장애는 해소**되었습니다. 이 기록은 Work Packages의 `CA-QC.hot`만 갱신합니다. 다른 국가·기존 저장본·Case Study·운영 DB는 변경하지 않습니다.

## 읽은 자료와 범위

- [CSA M87 공식 읽기 전용 원문](https://community.csagroup.org/docs/DOC-3695): 뷰어 84페이지 중 일반 확인표에 관련된 인쇄 pp.11–29(뷰어 31–49), p.38(58), pp.40–46(60–66)를 시각 열람했습니다. 1988-07, 1989-05 정정 지시(뷰어 5, 13), 관련 교체 페이지 17, 표 교체 페이지 8·12·20도 확인했습니다. 규격 전체 84페이지를 전수 검수했다는 뜻이 아닙니다. 특수 용접 공정, 설비 설계·정격 산정·배관 시스템의 적합성은 이번 일반 확인표 범위 밖입니다.
- [퀘벡 공식 CSTC](https://www.legisquebec.gouv.qc.ca/en/pdf/cr/S-2.1%2C%20R.%204.pdf): 검색 서비스가 제공한 공식 2025-07-15 통합본 발췌의 3.14.1–4를 재확인했습니다. 3.14.2는 M87을 인용하지만 **7.8.2.2를 제외**합니다. 3.14.3의 용기 작업 조건을 일괄 안전 승인으로 바꾸지 않습니다. 이번에 CSTC 전문을 새로 읽었다는 뜻은 아닙니다.
- [퀘벡 공식 RSST](https://www.legisquebec.gouv.qc.ca/en/pdf/cr/S-2.1%2C%20R.%2013.pdf): 공식 검색 발췌로 314–316의 **M94 5·6·8장** 참조를 재확인했습니다. M87의 가스 작업 장 번호와 같지 않습니다.
- [CSA 퀘벡 무료 열람 목록](https://community.csagroup.org/community/ohs/ohs-standards-view-access/quebec)과 사이트 검색에서 M94 원문을 확보하지 못했습니다. [CSA 답변](https://community.csagroup.org/message/105022)은 2022년 당시 구매 경로를 안내합니다. 과거 답변만으로 현재 유료 전용이라고 단정하거나 구매하지 않았습니다. M87 또는 최신 판매판으로 M94를 대체하지 않습니다.

## 기존 양식과의 대조·변경

| 범위 | 비교 결과 |
|---|---|
| 적용·예외 | 사업장 구분, 실제 용접 방식, 판본·조항·제외 근거를 기록하는 공란 추가 |
| 방식별 장비 | 기존 포괄 장비 확인란을 아크·저항·가스 방식별 조건부 확인란으로 나눔. 보호접지와 용접 귀환 회로, 방호·인터록, 가스 설비 적합성·누출·역류·역화를 구별 |
| 주변 위험·환기·용기 | 기존 가연물·가스/흄·측정 근거·보호 및 현장 적용 확인란과 대조. 도장·세정제 등 실제 재료와 주변 작업은 현장 위험평가에 포함해야 하며 양식이 자동 판정하지 않음 |
| 담당·중단·기록 | 기존 자격·역할·중단/재개·허가 기록란 유지. 새 장비 점검값 역시 복제·재사용 시 초기화 |
| 화재감시 | 기존 작업 중/종료 후 감시·최종 점검 기록과 현장 소방규정 판본·경과규정 확인 유지. M87의 수치를 CNPI 또는 모든 현장에 공통 기본값으로 이식하지 않음 |

새 문구 5개를 10언어로 의미 대조했습니다. `qcWeldingBasis`는 작업장 구분과 판본 선택 근거이며 법적 승인 자체가 아닙니다. `qcArcEquipment`는 보호접지와 용접 전류 귀환을 구별합니다. `qcResistanceEquipment`는 저항/접촉 용접이며 아크 작업으로 번역하지 않습니다. `qcGasEquipment`는 가스 역류와 역화를 구분합니다. `qcWeldingReviewNote`는 M87 대조와 M94 미완료, CSTC 예외를 모든 언어에서 유지합니다. 직접 만든 확인 문구이며 표준의 문장·표를 복제하지 않았습니다.

## 상태와 다음 확인

- **② 471/483, 97.5% 유지.** `CA-QC.hot` 전체를 종결하지 않습니다. M94 5·6·8장 원문 대조가 남아 있습니다. 다른 미완료는 IT 전기와 SA 4작업이며 총 6조합·12확인입니다.
- **③ 619그룹, 1857/1857, 100%.** 기존 614개 완료 해시를 유지하고 이번 5문구만 추가합니다. 새 문구의 번역 완료를 미열람 규격의 검수 완료로 계산하지 않습니다.
- 로그인 정보·CSA 원문 파일·원문 화면 이미지는 저장소에 저장하지 않습니다. 읽기 전용 제한을 우회하지 않았습니다.

## 검증

- 전체 자동 테스트 **250/250 통과**. 제한 환경의 로컬 연결·모듈 로딩 오류를 구분하고 정상 로컬 권한에서 순차 실행했습니다. 새 퀘벡 판본·안내에 맞게 기존 후속 검사의 기대값을 갱신한 뒤 전체를 다시 통과했습니다.
- 기존 614개 의미 검수, 89개 기본 양식, 66개 작업 완료 해시 유지. 새 5문구만 의미 검수 기록 추가. 890개 기본 양식·언어 조합과 720개 작업·언어 조합의 생성·출처·번역 연결 검사 통과.
- 새 회귀 검사는 M94 미완료 표시, M87/CSTC 제외 근거, 이전 안내 교체, 국가·작업 간 필드 혼입 방지, 현장값 초기화와 복제 독립성을 확인합니다. 기존 후속 검사의 버전 기대값도 퀘벡에 한해 갱신했습니다.
- 변경 JavaScript ESLint 및 Vite 클라이언트 빌드(891모듈) 통과. 기존 대형 번들 경고 유지.
- 운영 요청을 차단한 CA-QC 프랑스어 브라우저 흐름 통과: 모바일 편집, 저장 payload, 검수 확인, 실제 PDF 생성·보관 스냅샷, 인쇄 버튼/iframe 검사. 새 4확인란을 포함한 14페이지 PDF 전체를 렌더링해 시각 확인했습니다. 인쇄 에뮬레이션도 14페이지이며 빈 페이지·페이지 누락이 없고 콘텐츠 경계 차이는 최대 2픽셀입니다. 실물 프린터 및 실제 사용자 DB 검증은 아닙니다.
- 로컬 QA 산출물은 `.cache/regional-qa/batch30-csa/CA-QC`에 있으며 커밋하지 않습니다. CSA 원문과는 무관한 서비스 자체 생성 테스트 문서입니다.
