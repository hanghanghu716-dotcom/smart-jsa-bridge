# 한국·온타리오 기본 양식 9종 — 필드 및 전문용어 대조

확인일 2026-10-05. 새 양식 버전 `2026-10-05.17`. 한국 위험성평가·작업허가·TBM·점검표 4종과 온타리오 평가·작업절차·허가·Safety Talk·점검표 5종의 작업용 기록 범위다. 특수작업 허가의 전체 요건, 기업 전체 평가, Case Study·guideline·DB·운영 배포는 포함하지 않는다.

## 읽은 공식 자료와 접근 범위

- 한국 위험성평가: [고용노동부 고시 2024-76](https://www.moel.go.kr/info/lawinfo/instruction/view.do?bbs_seq=20241201150)의 HWPX 전문을 내려받아 제5–15조를 읽었다. 시행일은 2025-01-02다. [2026-09-23 개정안](https://www.moel.go.kr/info/lawinfo/lawmaking/view.do?bbs_seq=20260900747)은 행정예고로 확인되어 시행 기준으로 적용하지 않았다. 실시규정·기준 설정, 근로자 참여, 위험요인·대책·실행 확인, 공유·기록·재검토를 대조했다. 최초·수시·정기 및 상시평가의 조건은 구분하며 TBM만으로 상시평가 전체가 충족된다고 표시하지 않는다.
- 한국 TBM: [고용노동부 작업 전 안전점검회의 가이드](https://www.moel.go.kr/policy/policydata/view.do?bbs_seq=20230200455)의 첨부 PDF를 읽었다. 준비, 위험성평가 연결, 이해 확인, 불참자 전달, 사전 조치와 종료 후 의견, 예시 기록을 대조했다. 교육시간 인정 가능성은 안내되지만 이 양식 작성만으로 교육 인정 조건이 입증되지는 않는다. 개최시간 등 권고를 일률적 법정 의무로 만들지 않는다.
- 한국 허가: [KOSHA 2023 위험성평가 이행·점검 매뉴얼](https://oshri.kosha.or.kr/kosha/business/PublicInstitution_SafetyManagementRecord.do?articleNo=444292&attachNo=250186&mode=download)의 PDF 22쪽(인쇄 41–42쪽) 참고자료 01을 읽었다. 사전 평가·작업절차·조치, 신청·검토·발급, 현장조치 이행 확인·승인과 작업 중 확인을 대조했다. 공공기관 도급작업 예시를 전국 모든 업종의 허가 의무로 적용하지 않는다. 인용된 P-94-2021 자체는 확보하지 못했으므로 그 전문을 검수했다고 기록하지 않는다.
- 온타리오 평가·절차: [CCOHS Job Safety Analysis](https://www.ccohs.ca/oshanswers/hsprograms/job-haz.html)의 단계·위험·참여·통제 우선순위·실행 가능한 작업절차 연결을 대조했다. CCOHS 방법론은 온타리오의 모든 업종에 공통인 법규로 표시하지 않는다. [온타리오 기본교육 안내](https://www.ontario.ca/document/guide-occupational-health-and-safety-act-requirements-basic-awareness-training/general)의 공식 검색 색인 본문에서 기본교육과 작업별 정보·교육·감독을 구분했다.
- 온타리오 안전회의·일반 점검: [CCOHS Safety Talks](https://www.ccohs.ca/oshanswers/hsprograms/safety-talks-how-to.html), [Effective Workplace Inspections](https://www.ccohs.ca/oshanswers/prevention/effectiv.html) 본문을 읽어 이해·질의·후속 조치 및 점검 범위·위치·우선순위·담당/기한·완료·누락 범위·보고를 대조했다.
- 온타리오 점검 절차: [위원회·대표자 안내](https://www.ontario.ca/page/guide-health-and-safety-committees-and-representatives)의 공식 검색 색인 본문을 읽었다. 직접 요청은 403이었다. 해당 지정 근로자/대표자의 월간 점검과 전체 점검이 실무상 어려울 때의 연간 전체·월간 일부 일정, 예외 근거를 구분한다. 해당 서면 권고에는 21일 이내 회신과 수용 시 일정/불수용 시 사유를 기록한다. 일반 체크리스트 모두에 월 1회 의무를 부여하지 않는다.
- 온타리오 허가: [밀폐공간 출입허가 안내](https://www.ontario.ca/document/guideline-working-confined-spaces/entry-permit)의 공식 색인 본문(제10조 설명)을 읽었다. 직접 요청은 403이었다. 허가서의 현장 접근성 및 교대 전 적격자 확인을 일반 허가의 연결 필드에 반영한다. 작업·공간·위험/조치·유효기간·감시인·출입·구조/장비·측정 등 출입허가 전체 내용은 별도 작업별 절차와 연결해야 한다. 일반 PTW가 완성된 출입허가서로 자동 전환되거나 서명이 법정 필수라는 주장은 하지 않는다. 최신 통합 법령 전체를 직접 확보했다는 의미도 아니다.

## 양식별 대조·적용

작업명·장소·일자·담당자는 기존 공통 정보와 연결한다. 저장된 작업 순서·위험·대책은 재사용하고, 실제 참여·판단·일정 확인·측정·서명·조치 결과는 작업마다 입력한다.

| 양식 | 대조·보완 | 적용 경계 |
|---|---|---|
| KR.risk_assessment | 기존 작업·노출대상·위험/대책·기준·일자·검토·평가자에 현재 판단, 조치 완료, 실시규정 연결, 5단계 근로자 참여, 최초/수시/정기·상시평가 주기와 기록관리 추가 | 상시평가의 월간·주간·매 작업일 조건을 함께 기록. 전사 평가·실시규정·법정 보존 구현을 대체하지 않음 |
| KR.permit_to_work | 작업·허가종류/번호·절차·기간·조치/측정·역할·신청/확인/발행/인수·중단/인계/종료, 역량·동시작업·허가서 열람/확인 추가 | 공공기관 예시를 보편적 의무로 확장하지 않음. 교대 확인 필드는 실무 기록이며 모든 업종의 동일 법정 의무가 아님 |
| KR.toolbox_talk | 위험/대책·변경·의견·비상·조치·참여/진행, 평가 참조·중점 조치·사전 이행·불참자 전달·중지/신고·종료 후 의견·이해/후속 확인 | 법정 교육시간 인정 여부는 별도 조건. 양식만으로 교육 수료나 상시평가 완료가 되지 않음 |

| CA-ON.risk_assessment | 작업·노출대상·위험/대책·기준·일자·검토/참여·평가자, 현행 판단·조치 완료·적용근거·기록관리 | 과거 점수를 현행 현장 판단으로 간주하지 않음. 업종별 적용은 별도 |

| CA-ON.permit_to_work | 일반 허가 수명주기, 현장 조건·측정·역량·작업 조정·연결 계획·열람 위치·교대 전 확인 | 밀폐공간 기준을 일반 PTW의 전국 공통 조건으로 바꾸지 않음. 출입허가의 추가 요건은 해당 절차에 연결 |

## ③ 전문용어

새 8문구를 한국어·영어·독일어·일본어·프랑스어·이탈리아어·스페인어·아랍어·포르투갈어·러시아어에서 의미 대조했다.

- `krTaskFormScope`, `onTaskFormScope`: 작업용 기록의 범위와 사업장 전체 평가·전문검사·교육·작업별 허가의 차이를 유지했다. Ontario 프랑스어는 comité mixte/대표자 표현을 사용하며 프랑스 본토 DUERP 제도와 혼합하지 않는다.
- `krWorkerParticipation`: 기준 설정, 위험 식별, 위험성 결정, 대책 수립/실행, 실행 확인의 다섯 단계 참여를 기록한다. 최종 서명만으로 참여를 대체하지 않는다.
- `krAssessmentCycle`: 최초·수시·정기와 상시평가를 구분한다. monthly/weekly/each workday와 대응하는 각 언어의 주기를 대조했다. 단순 연간 점검 또는 TBM만을 상시평가 완료로 번역하지 않는다.
- `krTbmTransfer`: 사전 이행 확인·불참자 전달·중지/신고·사후 의견까지 연결한다. 교육 수료 보장으로 번역하지 않는다.
- `onInspectionBasis`: JHSC/대표자 적용 여부와 예외 근거를 남기고 주기를 조건 없이 확정하지 않는다.
- `onRecommendationResponse`: 해당 **서면** 권고, 접수일, **21일 이내** 회신, 이행일정/불수용 사유를 유지했다. 영업일 21일 또는 모든 점검결과의 시정완료기한 21일로 바꾸지 않는다.
- `permitAccessCheck`: 열람 장소 및 교대 전 확인자·시각·결과다. 자동으로 서명 완료나 적격성을 인정하지 않는다.

## 검증

- 전체 자동검사 **204/204** 통과. 새 9종 × 10언어에서 실제값 초기화, 재사용 내용 유지, 복제 독립성, 근거 보존, 이전 저장 양식의 버전 유지 및 국가별 요건 혼입 방지를 검증했다. 890개 기본 양식·720개 작업 양식 생성과 진행률/해시 검사도 포함한다. 이전의 ‘한국 허가/온타리오 점검에는 필드가 없음’ 가정 3곳은 새 요구사항에 맞게 수정하고 다른 관할에 대한 부정 검증을 유지했다.
- 변경 파일 ESLint와 Vite 클라이언트 빌드 **868 modules** 통과. 기존 번들 크기 안내가 남는다. 서버 사전 렌더링 배포 검증을 새로 수행했다는 의미는 아니다.
- 격리 브라우저 **4회** 통과: KR 한국어, CA-ON 영어, KR 아랍어, CA-ON 프랑스어. 모두 일반 PTW를 포함해 모바일 편집·JSA 연결·저장 요청·검토 확인·실제 PDF·출력 스냅샷을 확인했다. 최초 한국어 실행은 병행 빌드 중 첫 탐색 30초 제한을 초과했고, 준비된 서버에서 재실행해 통과했다. 기존 Windows 브라우저 종료의 Access denied stderr는 PASS와 종료코드 0 이후 발생했다.
- PDF **44쪽**(KR 9, CA-ON 13, KR 아랍어 9, CA-ON 프랑스어 13)을 Poppler로 렌더링해 전 페이지의 글자·표·필드 배치를 육안 확인했다. 잘림은 관찰되지 않았다. 아랍어 오른쪽 배치와 원본 점수의 왼쪽→오른쪽 순서를 확인했다. 일부 마지막 페이지에 입력란 1–3개만 남는 기존 페이지 밀도 문제는 유지된다. 전 언어의 모든 PDF 또는 실물 인쇄를 확인했다는 의미는 아니다.
- 기존 **512개 용어·60개 양식**의 완료 해시가 유지됐다. 새 8문구·9양식을 추가해 누적 **520개 용어·69개 양식**의 범위별 기록을 남겼다.
- ② **378/483 (78.3%)**, ③ **1566/1569 (99.8%)**, 합계 **1944/2052 (94.7%)**. ② 남은 105단계는 부분 근거 13개와 최종 확인 92개(기본 양식 20 + 작업 조합 72)다. ③ 남은 3개는 RU 고소·밀폐·전기 원어 묶음이다. 새 문구 8개로 ③ 분모는 24단계 늘었다. 동일 가중치 확인 단계 집계이며 작업시간이나 법적 인증률이 아니다.

외부 저장은 모의 응답으로 검사했다. 실제 계정 권한 재검증은 ⑤의 별도 항목이다. GitHub 검사는 별도로 실행되며 이 배치에서 운영 배포·DB 변경은 하지 않는다.
