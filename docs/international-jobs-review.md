# Official job connections without business registration

Reviewed 2026-11-03. Scope: all 15 supported countries / 19 locale routes.
This is a provider-by-provider access and publication review, not a claim that every vacancy or every national job market is covered. Existing JSA, Case Study, news and authoring content are unchanged.

Each new source has its own visible attribution/licence note on both the homepage and job list; initial HTML has the same note. No government endorsement is implied.

## Operating bounds and lifecycle

- Reuse the existing once-daily `government-jobs-daily` schedule. No per-visitor collection or new paid services/API keys.
- Seven prepared adapters; maximum six sources claimed per invocation. With Work24 disabled, six active sources make at most **17** requests/run: USAJOBS 2, Korea 5, Queensland 1, Castilla y León 1, Russia 2, Japan 1 list + at most 5 notice pages (currently 3 requests). Each response is capped at 2 MiB and each call at 12 seconds. The Japanese notices run concurrently and are read only for minimal metadata/deadlines; no recursive links, PDFs, images or full-text storage.
- Six claims maximum, locked atomically, 20-hour source cooldown. Independent sources run concurrently; each failure preserves other sources and existing records. Invocation timeout 100 seconds, below the Edge free-plan 150-second wall limit.
- Maximum 200 minimal records/source/import. Database upsert preserves operator withdrawal. No paid bulk downloads or AI translation.
- API access is free; hosting still depends on total project usage. These limits do not promise unlimited free hosting.
- Date-only Spanish deadlines keep their original date label and expire after that date in Europe/Madrid, including DST. The original notice governs any earlier exact time. Future application-start dates are not shown early.
- Russian API has no verified closing date; source rechecks and 48-hour stale handling apply. Missing items in a bounded result are not immediately declared closed. Actual withdrawal/earlier closure can precede the next source check; users must verify the original.
- Do not turn the metadata link directory into JobPosting schema, applicant processing or a full-text mirror.

## Japan alternative-source review (2026-11-03)

- MHLW: [current recruitment index](https://www.mhlw.go.jp/kouseiroudoushou/saiyou/oldinfo.html), direct ministry notices only. Its robots policy permits these paths. [RSS policy](https://www.mhlw.go.jp/rss/index.html) separately forbids redistribution; the adapter never fetches RSS. Applicant nationality, qualification and experience requirements stay in the original notice; no claim that all users can apply.
- [Saga prefecture open data](https://saga-job.jp/opendata/) / [terms](https://saga-job.jp/tos/) allow commercial use with attribution, but both documented XML files returned HTTP 404. The [general site terms](https://saga-job.jp/kiyaku/) have additional redistribution restrictions. No HTML scraping workaround activated.
- [Yamagata open-data terms](https://job.yamagata-iju.jp/pdf/opendata.pdf) require advance notification; the live site returned 503. No notification sent or import activated.
- [JREC-IN](https://jrecin.jst.go.jp/html/app/offer/dsc_utilization_j.html), [JOHAS](https://www.johas.go.jp/site-policy/) and [NITE](https://www.nite.go.jp/homepage/policy.html) were not cleared for this unlicensed commercial republication; no import.
- MHLW rechecks one current list and the five most recent eligible notices from the last 180 days per run. Missing notices are not declared closed from a bounded result; they become needs-verification after 48 hours. Source errors preserve existing records without refreshing verification. Explicit closure notices and known deadlines close automatically; operator withdrawal is never undone by re-import. A date-only deadline expires after that JST date; arrival cutoffs/eligibility remain governed by the original.
