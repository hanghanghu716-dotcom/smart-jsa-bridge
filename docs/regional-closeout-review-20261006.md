### 러시아 근거

- [884н 원문](https://minjust.consultant.ru/documents/25450): PDF pp.2–24를 시각 확인. 제1–9항의 적용과 제외, 제23–30항의 권한·조정·취소·새 허가·대장, 준비와 장비 확인, 가스용접의 중단·종료 및 밀폐공간 연계를 대조했습니다. 제26항의 새로운 위험 발생 시 취소/새 허가를 단순 재개 확인과 구분합니다. 제8항의 산업시설 제외와 특수 장비 설계는 이 일반 확인표의 인증 범위가 아닙니다.
- [287н 원문](https://minjust.consultant.ru/documents/55545): PDF p.5 제30항은 884н의 유효기한을 2031-09-01까지 연장합니다. 개별 허가의 기간 연장으로 적용하지 않습니다.
- [MChS 게시 1479 통합본](https://16.mchs.gov.ru/uploads/resource/2026-02-11/perechen-normativnyh-pravovyh-aktov-v-oblasti-pozharnoy-bezopasnosti_1770816913228588720.pdf): 표기는 2025-02-03 개정, 2026-02-02 저장. 제354–372항의 준비·감시·종료·일일 허가를 비교했습니다. 제372항의 임시 장소 예외는 다른 용접/산업 규정 면제와 같지 않습니다. 부록5는 청소 반경 표입니다. 2026년 새 규정 수립 계획을 시행된 대체 규정으로 취급하지 않았습니다. 이 확인은 인용한 통합본과 확인일 기준이며 장래 개정까지 보증하지 않습니다.

### 사우디 근거

- [NCOSH 최종 직종 규정](https://ncosh.gov.sa/media/gwwhsqoc/rowhro-25-ar.pdf): 제5–19조, 특히 제14조의 공인 전문교육·위원회 플랫폼 신청 경로를 원문으로 확인했습니다. 제15·17조는 시행 절차·지침의 별도 마련을 규정합니다. 교육 수료, 직종 면허와 현장 PTW는 서로 대체하지 않습니다. 기존 의료기록 비수집 원칙을 유지합니다.
- [EXPRO 정부 시설 작업허가 절차](https://expro.gov.sa/api/uploads/الدليل%20الإجرائي%20لتصريح%20الأعمال%20الخطرة.pdf): EOM-KSS-PR-000016-AR Rev 000, 2020-03-31. 제2절은 정부 시설 운영·유지보수 범위이고 제6.2절은 더 구체적인 작업 절차의 우선 적용을 요구합니다. 제6.3–6.7절의 발급/수락, 연계 허가, 변경 시 재평가, 종료·보관을 확인란으로 반영했습니다. 현재 관리본 확인 없이 해당 판본의 일회 연장 조건을 전국 공통 기본값으로 넣지 않습니다. 원본 양식·표는 복제하지 않았습니다.
- [NCOSH 규정 목록](https://www.ncosh.gov.sa/ar/knowledge-center/rules-regulations/administrative-systems/): 직종 규정, OSH 서비스 제공자 면허 규정, 의료 적합성 시행 지침은 서로 다른 문서입니다. 함께 게시된 사용자 준수 지침은 본문에 2021년으로 표시되므로 2026년 직종 면허 시행 근거로 승격하지 않았습니다. 이번 검색에서 적용 가능한 상세 시행 문서를 확보하지 못했으며, 미공포라고 단정하지 않습니다.
