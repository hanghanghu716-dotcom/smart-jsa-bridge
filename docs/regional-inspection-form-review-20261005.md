# ② 점검·절차·회의 5종 · ③ 남은 작업 문구 검수 — 2026-10-05.11

2026-10-05 검수. 영국 일반 점검표, 미국 Toolbox Talk·일반 점검표, 일본 안전작업절차서·일반 점검표를 필드별로 대조했다. 기존 20종에 5종의 종결 기록을 추가한다. 별도 고위험작업 조합과 현장별 법적 적용 판정은 종결하지 않는다. 기본 양식의 목적은 사용자가 현장 내용을 채우는 일반 작업 기록이며, 법정 전문검사·교육·조직 전체 관리체계를 대체하지 않는다.

## 새 작업 초기화 보완

새 시험에서 `startWork`가 저장 전 정리를 거치지 않은 과거/가져온 문서를 그대로 복제하는 경우를 재현했다. 화면에서는 정규화 때문에 표시되지 않더라도 실제값이 문서 내부에 남을 수 있었다. 새 작업 시작 시에도 `cleanPackage`를 거치게 하여 측정·작업자·확인 필드와 표의 과거값을 제거한다. 표준으로 잘못 분류한 실제값도 제거한다. 재사용할 작업내용·대책·원본 점수·도면은 보존하고 원본 객체를 수정하지 않는다. 기존 작업 이어하기와 과거 출력본 복원은 이 함수의 신규 작업 경로와 별개다.

## 검증 기록

기존 20개 양식과 392개 용어의 종결 해시는 변경 없이 확인했다. 생성된 양식·언어·근거가 바뀌지 않은 이전 기록을 재해시해서 덮어쓰지 않았다. 새 5개 양식·35개 용어만 종결 기록에 추가한다.

- 전체 자동시험 193개 통과. 과거 실제값이 표준값으로 잘못 분류된 입력도 새 작업·복제에서 비워지는지, 표준 작업내용과 원본이 유지되는지 검증했다.
- Vite 빌드 성공(859 modules), 변경 코드의 ESLint 통과.
- 격리된 브라우저에서 US 영어(밀폐공간 PTW 포함) 12쪽, GB 영어 8쪽, JP 일본어 8쪽, US 아랍어 8쪽의 PDF를 생성했다. 총 36쪽을 렌더링해 표·줄바꿈·페이지 경계·오른쪽에서 왼쪽으로 쓰는 문서의 배치를 확인했다.
- 모바일 및 미리보기 넘침, 검토 확인 절차, 모의 저장/출력 스냅샷을 확인했다. 이는 실제 계정과 DB 접근권한을 검증하는 ⑤단계를 완료했다는 뜻이 아니다.
- 집계: ② 334/483(69.2%), ③ 1429/1503(95.1%), 합계 1763/1986(88.8%). 동일 가중치 점검 항목 기준이며 시간 추정이나 법적 인증률이 아니다. 남은 ②는 근거 대조 13건과 최종 양식/작업 조합 136건, 남은 ③은 원어 역할 묶음 72개와 미사용 기본 사전 항목 2개다.
