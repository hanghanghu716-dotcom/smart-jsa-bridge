## ③ 전문용어 의미 검수

한국어·영어·독일어·일본어·프랑스어·이탈리아어·스페인어·아랍어·포르투갈어·러시아어 10종에 대해 다음 의미를 대조했다.

- `krAtmosphereRecord`: 측정과 평가, 담당자·장소·일시·결과 및 3년 보존. 앱 자체의 보존 보증으로 번역하지 않는다.
- `krEntryRestartNote`: 일시 중단 후 재측정, 한국의 119, 무방비 구조 금지, 조건부 예외 유지.
- `krElectricalReturnNote`: 설치자가 직접 잠금/표지를 제거하며 공구·접지·인원 확인 후 복전. 다른 사람의 임의 해제를 허용하지 않는다.
- `esEntryRolesNote`: 스페인 원어 recurso preventivo를 유지하고 외부 감시·연락·구조 업무와 자동으로 동일시하지 않는다.
- `esElectricalReturnNote`: autorizado/cualificado 및 고압 조건, 최초 조치 해제부터 충전 취급, 활선 승인 배제.
- `esPermitLifecycleNote`: 한 교대 이내, 변경/만료 후 갱신, 중지·보고·반환·보관은 NTP 지침으로 표현한다.

## 검증 기록

- 전체 자동시험 235/235 통과. 국가별 규칙 보존 시험에서 한국에 부적절한 공통 잠금 해제 예외 입력란 추가를 발견해 제거했고, 기존 한국 규칙 시험을 유지한 채 재실행했다.
- Vite 클라이언트 빌드 882개 모듈, 변경 코드 ESLint, 검수 목록·집계 및 지문 검증 통과.
- 기본 양식 890개 및 작업 양식 720개 언어 조합의 생성 확인. 이번 8조합 × 10언어의 공란·버전·출처·국가별 문구 격리·새 작업/복제 초기화·기존 저장본 유지 시험 포함.
- 격리된 브라우저 4개 흐름 통과: 한국/한국어, 스페인/스페인어, 한국/독일어 문서(스페인어 화면), 스페인/아랍어 문서. 모바일 편집, 모의 저장, 검토 확인, 실제 PDF 생성과 출력본 스냅샷을 검사했다. 실제 DB에 쓰지 않았다.
- PDF 74쪽(각 16/21/17/20)을 Poppler로 렌더링해 모두 시각 점검했다. 검사한 페이지에서 글자 잘림·겹침을 관찰하지 못했다. 기존의 여백 많은 연속 페이지와 표가 다음 페이지로 이어지는 배치는 남아 있다. 전체 10언어의 시각 검증 및 실물 인쇄를 완료했다는 뜻은 아니다.
- 이전 용어 561개·기본 양식 89개·작업 40개의 검수 지문 불변 확인. 신규 용어 6개·작업 8개를 추가해 의미 검수 567개, 작업 종결 48개를 기록했다.
- ② 446/483(92.3%), ③ 1,707/1,710(99.8%), 합계 2,153/2,193(98.2%). 잔여 40점 = 작업 최종 확인 24 + 출처 제한 13 + 러시아 원어 3. 신규 용어 6개가 추가돼 ③의 전체 확인 단계도 18개 증가했다. 이는 확인 단계 집계이며 시간이나 법적 적합성 인증 비율이 아니다.
- 기존 번들 크기 경고는 남아 있다. 실제 계정 접근 및 운영 배포를 이번에 반복하지 않았다.

검수 종결은 위 앱 확인란 범위다. 표준 전문, 업종별 특례, 실제 자격·현장 설계·구조능력·허가 적법성 인증, 실제 계정 접근 시험 및 운영 배포는 포함하지 않는다.
