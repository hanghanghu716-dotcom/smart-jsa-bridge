# 캐나다 3개 주 × 4개 작업 검수 — 2026-10-06

② 요건·양식과 ③ 전문용어, batch 21. 앨버타·BC·온타리오의 고소/밀폐/전기/화기 12조합을 검수했다. 현재 작업 확인란 42개, 새 문구 7개 × 10언어를 추가했다. 기존 89개 기본 양식, GB/US/CA 12개 작업, 541개 용어 완료 기록은 그대로 유지한다.

## 범위와 근거

완료 범위는 기존 작업별 확인란 목록의 적용 조건·대책·역할·중단/재개·기록·예외를 대조하고 편집 가능한 문서에 연결하는 것이다. 법정 허가 발급, 모든 업종의 완성 서식, 현장 적합성이나 구조능력 인증을 뜻하지 않는다. 작업 조건·자격·실측값은 사용자가 매 작업 확인하며 과거 값은 자동 승인 근거로 사용하지 않는다. Case Study, guideline, 공개 콘텐츠, DB는 변경하지 않는다.

앨버타 검색 사이트 하단에는 March 2023이라는 과거 안내가 남아 있어 그 문구만으로 현행 여부를 판단하지 않았다. [정부 OHS Code 안내](https://www.alberta.ca/occupational-health-and-safety-code)가 현재 연결하는 [2025-03-31 통합 PDF](https://kings-printer.alberta.ca/documents/OHS/OHSCode_March_31,_2025_(rep_s850)_only.pdf)의 개정 범위(210/2024까지), 대상 조항을 검색 원문과 교차 확인했다. 로컬 PDF 다운로드는 403, 웹 도구의 화면 렌더링은 실패했으나 웹 도구가 제공한 PDF 조항 텍스트를 확인했다. [2025-04 밀폐·제한공간 안내](https://ohs-pubstore.labour.alberta.ca/download/sample/154)에서도 두 공간의 범위 차이를 확인했다. 2026년 의견수렴 문서는 시행 규정으로 취급하지 않는다.

온타리오 일반 e-Laws URL은 웹 도구에서 오류가 났다. 해당 사이트의 공개 `laws/api/v2/legislation/en/doc-search/regulation/{번호}` 원문을 읽어 `state=current`와 통합 시작일을 확인했다: 213/91은 2026-04-20, 632/05는 2016-07-01, 851은 2022-07-01, Fire Code 213/07은 2026-01-01. 이는 조회일과 서로 다른 날짜다. 출처 원문 사본은 임시 검증 폴더에만 두고 배포 자료에 포함하지 않는다.

## ③ 문구 의미 확인

7개 키는 ko/en/de/ja/fr/it/es/ar/pt/ru로 대조했다. `fallServiceRelease`는 점검과 사용중지 후 복귀 근거를 구분하고 자동 재사용 승인을 하지 않는다. `standbyArrangement`는 위험별 위치/통신/간격/인계를 묻는다. `rescueNotification`은 시작·전원 퇴출 통보, 약정/훈련과 조건부 통보 예외를 구분한다.

`abEntryScopeNote`의 restricted/confined 구분과 tending worker, `bcStandbyScopeNote`의 20분 최대 간격과 고위험 상시 감시, `bcGroupScopeNote`의 2인·개인 잠금·해제 구별, `onHotEquipmentNote`의 매일/사용 전 점검과 월간 누설시험이 각 언어에서 유지된다. 현지 역할명은 다른 나라의 자격 명칭으로 치환하지 않는다. 기존 541개 용어 해시는 재작성하지 않는다.

## 검증

대상 자동시험 39/39와 전체 자동시험 220/220이 통과했다. Vite 빌드(876개 모듈), 변경 JavaScript 파일의 ESLint 및 diff 검사를 통과했다. 기존 큰 번들 경고는 남아 있다. 12조합의 전체 문서 × 10언어와 근거·버전·현재값 모드·렌더러를 해시로 고정하며, 후속 변경 시 최종 확인 상태가 자동 유지되지 않게 검사한다. 기존 541개 용어·89개 기본 양식·12개 작업 조합의 검수 해시는 유지했다.

격리 브라우저에서 AB 영어, BC 영어, ON 프랑스어, BC 아랍어의 네 흐름을 통과했다. 네 작업별 허가 섹션, 원본 JSA 가져오기, 모바일 편집, 저장 데이터, 검토 확인, PDF 생성과 출력 당시의 스냅샷을 검사했다. 외부 저장 요청은 대체 응답을 사용했으며 실제 계정이나 DB에 자료를 쓰지 않았다.

생성한 PDF는 각각 19·18·21·18페이지로 총 76페이지다. 모든 페이지를 이미지로 렌더링해 확인했으며 새 안내문의 잘림이나 겹침은 발견되지 않았다. 일부 후속 페이지의 여백은 남아 있다. 모든 언어의 시각 조합, 실제 프린터, 실제 계정 및 서버 사전 렌더링 검증을 이번 결과에 포함하지 않는다.

누적 집계: ② 422/483 확인점(87.4%), ③ 1,650/1,653 확인점(99.8%). 합계 2,072/2,136(97.0%)이며 64개가 남는다(출처 제한 13, 작업별 최종 확인 48, 러시아 원어 용어 3). 이는 정의된 검수 확인점의 집계이며 모든 업종의 법적 적합성이나 잔여 작업시간 비율을 의미하지 않는다.
