- `deElectricalRelease`: 독일의 설비 담당과 작업 담당 역할 및 시작/종료 인계를 유지하고 다른 나라 자격명으로 번역하지 않음.

- `deEntryLifecycleNote`: 재발급 또는 연장과 대책 재확인, 작업지침 대체/감시 예외의 조건부 성격 유지.

- `frHotLifecycleNote`: 여러 날의 허가를 다년 허가로 옮기지 않음. 일일·교대·조건 변경 확인과 2시간/5년 지침 권고를 법정 공통기간으로 과장하지 않음.
