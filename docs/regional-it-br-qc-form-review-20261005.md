## ③ 전문용어

새 문구 `itTaskFormScope`, `brTaskFormScope`, `qcTaskFormScope`, `brRiskCoverage`, `brReviewCycle`, `qcRiskCoverage` 6개를 한국어·영어·독일어·일본어·프랑스어·이탈리아어·스페인어·아랍어·포르투갈어·러시아어에서 의미 대조했다.

- DVR/DUVRI, PGR/NR/DDS/CIPA, programme de prévention/plan d’action 명칭은 문서 언어와 무관하게 유지한다.
- 이탈리아 formazione와 addestramento는 교육과 실습을 구분한다. 일반 모임을 자격·수료 인정으로 번역하지 않는다.
- 브라질 psychosocial은 업무 관련 요인을 가리키며 개인의 진단명 입력을 요구하지 않는다. SST는 산업안전보건 관리체계이고 3년은 인증 조건부 상한이다. 위험평가 조기 검토와 정기 검토를 별개로 읽도록 했다.
- 퀘벡 16 ans et moins는 **16세 포함 이하**다. 영어 under 16로 축소하거나 프랑스 본토 제도와 혼합하지 않았다. 작성자의 해당 여부 판단란이며 미성년자 작업 허가 기능이 아니다.
- 기존 검수 문구는 수정하지 않고 새 문구만 연결했다. 실제 판단을 받는 새 필드는 `verification/runtime`이다.

## 검증

- 전체 자동검사 **202/202** 통과. 새 12종 × 10언어에서 원본 독립성, 현장값 초기화, 재사용 값/근거 보존, 이전 양식 버전 유지, 허가서·타 국가 혼입 방지를 확인했다. 890개 기본 양식·720개 작업 양식 생성 검사와 진행률/해시 검사도 포함한다.
- 변경 파일 ESLint 및 Vite 클라이언트 빌드 **866 modules** 통과. 기존 번들 크기 안내가 남는다. 전체 사이트의 서버 사전 렌더링 배포 검증을 새로 했다는 의미는 아니다.
- 격리 브라우저 **4회** 통과: IT 이탈리아어, BR 포르투갈어, CA-QC 프랑스어, BR 아랍어. 모바일 편집·JSA 연결·저장 요청·검토 확인·실제 PDF·출력 스냅샷을 검증했다. 외부 저장은 모의 응답이므로 실제 계정 권한 재검증으로 집계하지 않는다. Windows 브라우저 종료의 기존 Access denied stderr는 종료코드 0과 PASS 이후 발생했다.
- PDF **43쪽**(IT 11, BR 11, CA-QC 11, BR 아랍어 10)을 Poppler로 렌더링해 전 페이지를 육안 확인했다. 문자·표 잘림은 관찰되지 않았고 아랍어 오른쪽 배치와 원본 점수의 왼쪽→오른쪽 순서를 확인했다. 일부 마지막 페이지에 입력란 1–2개만 남는 기존 페이지 밀도 문제는 유지된다. 전 언어의 모든 출력·실물 인쇄를 확인했다는 의미는 아니다.
- 기존 **506개 용어·48개 양식**의 완료 해시는 모두 유지됐다. 새 6문구·12양식을 추가해 누적 **512개 용어·60개 양식**의 범위별 완료 기록을 남겼다.
- ② **369/483 (76.4%)**, ③ **1542/1545 (99.8%)**, 합계 **1911/2028 (94.2%)**. ② 잔여 **114개**는 원문/범위 미해결 13개와 최종 확인 101개(기본 양식 29 + 작업 조합 72)다. ③ 잔여 **3개**는 RU 고소·밀폐·전기 원어 묶음이다. 새 문구 6개로 ③ 분모가 18단계 늘었다. 동일 가중치 확인 단계 집계이며 작업시간이나 법적 인증률이 아니다.
