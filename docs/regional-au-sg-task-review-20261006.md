# ②·③ 호주·싱가포르 작업별 검수 — 2026-10-06

범위: AU·SG × 고소·밀폐·전기·화기 8조합. 현장 확인란 49개를 보완하고 새 문구 7개를 10개 문서 언어로 대조했다. 기존 기본 양식과 저장본은 유지한다. Case Study, guideline, DB 변경은 없다.

## 공식 자료 확인

호주는 Safe Work Australia의 현재 게시 페이지와 다운로드를 대조했다. 모델 지침의 지역별 법적 효력은 [입법 안내](https://www.safeworkaustralia.gov.au/law-and-regulation/legislation)로 구분한다. Victoria 미채택과 다른 주·준주의 변형·별도 면허를 유지하며, 모델 지침 검수를 각 주의 법률 전수 검수로 세지 않는다.

고소 PDF는 2022 경로지만 표지는 October 2018이고, 현재 게시 페이지에서 같은 파일을 연결한다. 용접은 기존 2019 경로 대신 [현재 게시 페이지](https://www.safeworkaustralia.gov.au/doc/model-code-practice-welding-processes)의 July 2020 PDF를 추가했다(게시일 2021-05-28과 문서 판본을 구분). 전기는 2018, 밀폐공간은 November 2024 판본이다. 기존 출처 이력은 유지한다.

싱가포르 SSO는 웹 검색 도구에서 403이 발생했으나 공식 서버의 공개 HTML을 직접 읽었다. 최초 페이지는 일부 조항만 포함하므로 완료 근거로 쓰지 않고, 각 Part/First Schedule 보기에서 본문을 확보했다. 밀폐공간, 고소, 선박 규정은 2024-06-01 시행 개정 내용을 포함한다. 공통 규정은 서버가 제공한 현재 canonical 주소 `354A-RG1?DocDate=20260929`로 14·16조 본문을 읽었다. 단순 목차나 옛 검색 발췌로 대체하지 않았다.

## ③ 10언어 의미 대조

한국어·영어·독일어·일본어·프랑스어·이탈리아어·스페인어·아랍어·포르투갈어·러시아어를 대조했다.

- `heightAccessCheck`: 작업발판·개구부·취약 지붕·사다리의 적합성/방호/고정/접근 확인. 자동 설계 적합 판정이 아니다.
- `sgMarineEquipmentCheck`: 선박 전기·가스 보호 및 감전방지기 6개월 시험을 다른 장비 검사 주기와 구분. 습윤 상태의 감전 예방을 모든 습윤 작업 금지로 과장하지 않는다.
- `sgFireEscalation`: 훈련된 감시인·장비·주변 감시·자체 통제 불가 시 즉시 SCDF 통보.
- `sgRescueInspection`: competent person을 다른 국가 면허로 치환하지 않음. 최소 월간 또는 당국 지정 간격, 검사 기록 2년 이상 보관.
- `auEntryReviewNote`: 주/준주 적용, 재확인 사유, 연속 외부 감시, 감시인의 구조 진입 금지, 전원 퇴출·사고별 보관.
- `sgEntryReviewNote`: 측정 순서, 2명 이상 조건, 위험 대기 퇴출·새 허가, 일일 검토와 만료 분리, 10(2) 예외 미승인.
- `sgElectricalBoundaryNote`: LEW 면허와 authorised high voltage switching engineer 역할, 고전압 허가·열쇠·종료/취소, 활선 승인과 분리.
