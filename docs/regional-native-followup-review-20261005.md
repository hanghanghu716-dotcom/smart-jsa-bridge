# Native terminology follow-up — 2026-10-05

Review version: 2026-10-05.13. Scope: 37 native task/role bundles, preserved alongside the previously reviewed translated role framing in all ten document languages. Case Study, guideline content, DB and production deployment are outside this batch.

## What was checked

Each row below records the meaning comparison and source boundary. Keeping a local role name in a translated form does not give the named person a licence or authorisation. This closes only the stage-3 lexical/preservation check; stage-2 full legal applicability remains separate. Official search-index clause excerpts were used where explicitly stated; those are not described as a fresh full-document review. Saudi descriptive translations are not labelled statutory role names.

Five native labels were corrected: KR electrical locking device plus tag; JP oxygen-deficiency classifications and full operations-chief title; Quebec fall-arrest/rescue vocabulary; separately named ES authorised/qualified workers; SA fire watcher. Existing saved forms retain their text and version. New task sections use version 2026-10-05.13.

The BR electrical reference now targets the dated 2019 NR-10 PDF valid through 2027-05-31. The existing ten-language edition notice and current-work edition-confirmation blank already distinguish the 2027-06-01 replacement; they were retained, not duplicated.
