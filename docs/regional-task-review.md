# 작업별 세부 요건·전문용어 검수 기록

기초 검수일: 2026-10-03. 추가 검수일: 2026-10-04. 현재 작업별 PTW 항목 버전 `2026-10-04.1`.

최신 추가 결과는 [②·③ 추가 검수 기록](regional-requirements-review-20261004.md)에 정리했다. 16개 국가/지역·17개 작업 조합에 32개 입력란을 추가하고 10개 언어에 반영했다. 아래 기초 검수와 이번 추가 검수의 범위를 합쳐도 모든 현행 법률·전문용어를 전수 검수한 것은 아니다.

## 단계 구분

| 단계 | 상태 |
|---|---|
| ① 지원 국가·언어 확인 | 완료: 14개국, 18개 국가·지역 설정, 10개 언어 |
| ② 국가별 명칭·양식 및 세부 요건 | 기본 구현 완료. 고소·밀폐공간·전기·화기 4개 작업의 항목·적용 범위 대조와 코드 수정 진행. 아래 미완료 조건 존재 |
| ③ 다국어화·전문용어 | 번역 연결 완료. 이번 항목의 현지 용어를 공식 자료와 대조해 수정. 모든 분야·모든 전문용어의 전수 검수 완료는 아님 |
| ④ 저장·복제·출력 | 코드 및 격리 시험. 작업별 검수 근거·버전을 저장본과 출력 당시 데이터에 함께 보존 |
| ⑤ 실제 사용 검증 | 10월 4일 두 실제 계정의 기본 저장·복원·접근권한 시험 수행. 국가별 최종 사용 검증은 미완료. 이번에는 ②·③을 우선하며 ⑤를 재개하지 않음 |

## 코드에 반영한 결과

작업별 서류 묶음의 국가별 양식 영역에서 고소·밀폐공간·전기·화기를 명시적으로 선택한 뒤 작업허가서를 추가한다. 선택한 작업의 확인 항목만 새 허가서의 서명란 앞에 붙는다. 기본 묶음에 작업허가서를 자동 추가하거나 작업명 문자열에서 허가 필요 여부를 추측하지 않는다.

| 작업 | 기존 공통 허가서에서 부족했던 부분 | 반영 |
|---|---|---|
| 고소 | 단순 PPE·비상계획만으로는 작업 회피, 집단방호, 추락 제동거리와 구조 준비를 구분하지 못함 | 작업 회피·발판·난간, 부착점·여유거리, 개구부·취약면·낙하물, 기상·장비, 구조 및 중지 조건 |
| 밀폐공간 | 출입·감시·감독 역할, 재측정, 유입 차단과 구조 인력의 분리 부족 | 공간·출입 필요성, 역할, 측정 대상·현장 허용기준, 차단, 환기·호흡보호, 구조, 출입 인원·시각, 퇴출·재허가 |
| 전기 | 일반 차단란만으로 전원 분리와 무전압 확인을 혼동할 수 있음 | 전원·역송전·유도전압 식별, 잠금·표지, 검전기와 확인자, 접지·인접 충전부, 작업 종료·복전. 정전용 확인이 활선 승인 절차를 대체하지 않도록 명시 |
| 화기 | 일반 화재위험 표시만으로 사후 감시·반대편 전파·흄을 기록하기 어려움 | 가연물·벽 반대편·하부, 화재감시자·종료시각, 가스·흄·분진, 용기 잔류물·장비, 중지 조건 |

공통으로 적용 규정·작업 분류·별도 허가서 참조와 교육·자격·권한 확인란을 둔다. 밀폐·전기·화기는 측정기 식별/교정/기능 확인, 기준, 실측값/단위, 측정시각, 측정자 기록을 분리한다. 이 값은 모두 매 작업 입력값이며 복제 시 이전 값을 보존하지 않는다. 법정 숫자를 전세계 공통 기본값으로 입력하지 않는다.

## 검수에서 확인한 주요 근거

- [MOM 고소작업 허가 설명](https://www.mom.gov.sg/-/media/mom/documents/safety-health/factsheet-on-wahamendmentregulations.pdf): 3m 초과 위험에 대한 공장 적용과 유효 방호 예외를 함께 확인해야 한다. 단일 높이만으로 허가 여부를 판정하지 않는다.
- [OSHA 1910.146](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.146): 일반산업 범위, 허가서 정보와 담당 역할, 작업 완료/금지조건 발생 시 종료를 대조했다. 건설업용 완성 양식으로 표시하지 않는다.
- [WorkSafeBC Part 9](https://www.worksafebc.com/en/law-policy/occupational-health-safety/searchable-ohs-regulation/ohs-regulation/part-09-confined-spaces): 9.13의 허가 조건과 9.15의 교대·인원/감독 변경 재승인을 구분했다.
- [INSST 밀폐공간](https://www.insst.es/materias/riesgos/seguridad-en-el-trabajo/espacios-confinados): 작업허가, recurso preventivo, 구조 수단과 서면 절차를 구분했다.
- [CNESST 전기설비](https://www.cnesst.gouv.qc.ca/fr/prevention-securite/identifier-corriger-risques/liste-informations-prevention/travail-sur-installations-electriques)와 [INRS habilitation](https://www.inrs.fr/risques/electriques/habilitation-electrique): 프랑스어가 같아도 관할별 관리 용어·권한 체계는 별도다.
- [MTE 2026-09-02 안내](https://www.gov.br/trabalho-e-emprego/pt-br/noticias-e-conteudo/2026/setembro/trabalho-em-altura-veja-o-que-muda-nos-treinamentos-e-nas-escadas-fixas-verticais): NR-35 교육 방식과 고정 수직사다리 변경을 확인했다. [관보 원문](https://www.in.gov.br/web/dou/-/portaria-mte-n-1.259-de-15-de-julho-de-2026-719529365)은 이번 접근에서 502여서 시행·경과조건을 코드의 확정 판정값으로 넣지 않았다.
- 러시아 [2025 개정 공표 위치](https://publication.pravo.gov.ru/document/0001202505300025)는 접근 시간이 초과됐다. 원래 Минтруд 페이지의 과거 종료일을 현재 만료라고 단정하지도, 개정 전문을 읽었다고 처리하지도 않았다.

## 완료 판정과 다음 검수 단위

이번 결과는 **작업별 입력란·관할별 용어·적용 범위 분리 구현과 출처 대조**다. 72개 조합의 현행 법률 전수 검수 완료가 아니다. 기록된 미완료 항목을 남겨 두고 일반적인 외부 자문 요청으로 사용자에게 넘기지 않는다.

후속 검수는 (1) 접근하지 못한 현행 조문·경과규정 확보, (2) 국가 내부 관할과 업종/작업의 적용 조건, (3) 자격·측정 기준·허가 유효시간·보존기간의 조건별 검수, (4) 확인한 조건에 맞는 필드·검증 로직 반영 순이다. 실제 계정 접근권한은 별도 ⑤단계다.

## 기초 구현의 소프트웨어 검증 (2026-10-03)

- 자동 테스트 132개 통과. 18개 국가·지역 × 4개 작업 생성, 선택 격리, 현장값 재사용 방지, 복제 독립성, 근거/버전 보존, 10개 언어 연결 포함.
- Vite 빌드 통과.
- 18개 국가·지역의 현지 언어 화면에서 네 작업을 모두 선택해 허가서 추가 → 모의 저장 → 미리보기 → 실제 PDF 생성 → 출력 당시 데이터 보관 시험 통과. 모바일 가로 넘침 검사 포함.
- PDF에서 측정표의 열 제목만 이전 페이지에 남는 현상을 발견해, 제목과 첫 데이터 행 사이를 페이지 분할 후보에서 제외했다.
- 브라우저·실제 PDF 시험은 원격 요청을 차단한 모의 저장으로 실행한다. 실제 DB 계정 접근권한 시험과 구분한다.
- 법률·번역 정확성은 테스트 개수로 증명되지 않는다. 위 표의 범위·미완료 상태가 우선한다.
