`content-review-batch21.json`에 읽은 범위, 원본 PDF/HWP 또는 페이지 이미지의 SHA-256, 개정 대조 결과와 미확인 사항을 구분해 기록했다. 기존 출처 캡처와 의미는 변경하지 않았으며, 새 현행 조문 확인은 별도 검수 근거로 연결했다. 원문 전체나 편집 주석을 재배포하지 않는다. 원본 파일 해시와 검수자의 요약문을 혼동하지 않는다.

기존 검수 이력은 수정하지 않았다. 테스트는 새 변경사항을 역적용하여 과거 내용과 해시를 재구성하고, 현재 177개 고유 검수 영역의 내용 해시·근거 지문, 물리적 안전조치, 사우디 미완료 3건, 공개 차단 및 후속 단계 미진행을 확인한다.

첫 CI 실행에서 범위 집계의 입력 해시와 두 추가 테스트 파일의 과거 이력 복원 누락을 발견해 수정했다. 범위 집계를 현재 초안에서 재생성했으며, 과거 검수 기록과 판정은 바꾸지 않았다. 관련 로컬 테스트 51개, 범위 집계 검사 및 두 근거 연결 검사가 통과했다. 전체 애플리케이션 검증 결과는 해당 커밋의 CI 결과로 별도 확인한다.
