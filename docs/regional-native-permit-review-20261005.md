# ② 기본 허가서 3종 · ③ 원어 용어 32묶음 — 2026-10-05.12

이번 범위는 GB·AU·SG·US·CA·CA-AB·CA-ON·CA-BC의 고소/밀폐/전기/화기 원어 용어 32묶음, 신규 허가서 안내 1개(10언어), 미국·호주·싱가포르 기본 허가서 3종이다. 원어 용어는 자격을 자동 판정하는 목록이 아니라 현장 절차의 역할을 확인하는 표제다. 용어 종결은 ②의 별도 작업 조합 종결로 계산하지 않는다.

## 기본 허가서의 필드 대조

미국: 1910.146(d) 작업 조정·교육, (e)/(f) 역할·시간·위험·조건·기록, 1910.252(a)(2)(iv) 사전 현장 확인과 승인 구분에 대조했다. 호주: SWA 2024 코드 4.3/부록 C, NSW 화기 안내의 책임자·통제·확인·기록 흐름과 대조했다. 싱가포르: WSHC 밀폐공간 7절, MOM WAH Annex A, Marine manual 4–5절의 신청·평가·발행·연계·종료 흐름에 대조했다.

공통 작업정보·scope, permitType/permitProcedure/validity, 위험·조치 표, isolation/ppe, 측정항목·값·시각·측정자, emergency, applicant/siteVerifier/issue/acceptance, suspension/handover를 확인했다. 세 양식에 competency(역할·교육·역량·자격 확인), permitCoordination(동시·연계 작업), permitScope(기본 기록 범위)를 추가했다. 기존 검수 문구를 재사용하고 새 안내는 한국어·영어·독일어·일본어·프랑스어·이탈리아어·스페인어·아랍어·포르투갈어·러시아어에서 절차·업종·관할·별도 허가·승인 부여 없음의 뜻을 대조했다.

이 종결은 **일반 허가 기록의 필드 구조**에 한정한다. 각 나라의 완전한 밀폐공간 출입허가 또는 해양 화기허가 법정 양식으로 인증하지 않는다. 특수 작업 보충 항목과 현장 절차·별도 허가를 계속 확인해야 한다. 기존 GB 등 25개 양식은 새 버전으로 바꾸지 않는다.

## 미사용 문구와 검수 기록

실제 호출이 없는 기본 사전 2개(People at risk, Applicant / site check / permit authority signatures)를 제거했다. 현재 화면은 더 구체적인 대상자 필드와 각각의 허가 역할 서명을 사용한다. 저장된 문서에는 라벨 문자열이 보관되므로 과거 출력 라벨을 다시 생성하거나 변경하지 않는다. 두 항목을 검수 완료로 세지 않고 대상에서 제외한다.

원어 검수 해시는 실제 원어와 10개 언어의 생성된 역할 라벨을 함께 고정한다. 이후 원어 또는 번역된 주변 설명이 변경되면 기존 완료 기록으로 통과할 수 없다. 기존 427개 용어와 25개 양식의 해시를 재작성하지 않는다.

## 검증 결과와 최종 집계

- 전체 자동시험 196개 통과, Vite 빌드 860개 모듈 처리 성공, 변경 코드 ESLint 통과.
- 격리된 브라우저에서 미국 영어 12쪽, 호주 영어 13쪽, 싱가포르 아랍어 16쪽의 실제 PDF를 생성했다. 모바일 편집, 모의 저장·복원, 검토 게이트, 출력 스냅샷 보존, 미리보기 넘침과 아랍어 점수 방향 검사를 통과했다. 41쪽 전체를 이미지로 렌더링해 긴 원어 역할 라벨과 표 경계를 확인했다. 실제 계정 검증 완료를 의미하지 않는다.
- 기존 427개 용어·25개 양식 해시가 변경되지 않았음을 확인했다. 새 원어 32개·안내 1개를 더해 용어 종결은 460개, 양식 3개를 더해 기본 양식 종결은 28개다.
- ② 국가별 요건: 337/483개 체크포인트 완료(69.8%), 146개 남음(30.2%). 근거 보완 13개와 최종 검수 133개(기본 양식 61개·작업별 항목 72개)다.
- ③ 전문 용어: 1460/1500개 체크포인트 완료(97.3%), 원어 용어 40개 묶음의 최종 검수 남음(2.7%). 미사용 문구 2개는 완료로 처리하지 않고 분모에서 제외했다.
