## 읽은 공식 자료와 적용 범위

- [INRS DUERP·예방조치](https://www.inrs.fr/demarche/document-unique/ce-qu-il-faut-retenir.html): 작업 단위 평가를 DUERP 및 해당 조치 목록/Papripact에 연결한다. 인원 규모별 체계를 임의 자동 선택하지 않으며, 작업용 PDF를 전체 DUERP·보존 시스템이라고 표시하지 않는다.
- [INRS 정보·교육](https://www.inrs.fr/demarche/formation-information/ce-qu-il-faut-retenir.html): 작업별 설명, 제조사 지침, 변경·비상·신고에 대조했다. 일반 안내 페이지의 오래된 교육 대상·기간을 최신 전 업종 규칙으로 이식하지 않았다. Causerie sécurité는 필요한 직무교육의 수료증이 아니다.
- [INRS 외부업체 사전조정](https://www.inrs.fr/risques/entreprises-exterieures/mesures-prevention-prealables-intervention): 해당 외부업체 작업의 합동 사전확인, 간섭위험, 절차·지침 전달을 기존 조정란에 연결한다. Mode opératoire는 별도 Plan de prévention이나 건설 조정문서를 대신하지 않는다.
- [INRS ED 6513, 2023년 4월, 1–2쪽](https://www.inrs.fr/dam/jcr:d975c3d3-384d-46a8-9054-dfd9b889028e/ed6513.pdf): 점검 계획, 작업 관찰·의견, 결과 공유와 조치 추적에 참고했다. CSE용 방법 자료를 일반 점검표의 필드 설계에 사용했으며 CSE 절차 완료나 법정 설비검사를 인정하지 않는다.
- [BOE Ley 31/1995](https://www.boe.es/buscar/act.php?id=BOE-A-1995-24292): 15–20, 23–24조 본문에서 평가·조치·담당·기한·자원·추적, 정보/교육·비상·회사 간 조정을 대조했다. 예방체계 전체와 짧은 작업 기록을 구분했다.
- [BOE RD 39/1997](https://www.boe.es/buscar/act.php?id=BOE-A-1997-1853): 3–9조의 작업·노출대상·평가기준·역량·재검토·계획 자원에 대조했다. 의료정보를 일반 작업양식에 요구하지 않으며 위험별 측정 방법이나 점검 주기를 일률적으로 계산하지 않는다.
- [INSST 예방관리](https://www.insst.es/materias/transversales/gestion-prevencion): 작업절차, 정보·교육 및 예방 담당 조직과의 연결을 대조했다. 업종별 기술기준이나 CAE 전체 절차 검수로 확대하지 않는다.

## ③ 새 문구 4개 × 10개 언어

`frTaskFormScope`, `esTaskFormScope`, `preventionPlanLink`, `actionResources`를 한국어·영어·독일어·일본어·프랑스어·이탈리아어·스페인어·아랍어·포르투갈어·러시아어에서 대조했다. DUERP/Papripact/CSE와 스페인 Plan de prevención/CAE의 명칭은 문서 언어와 무관하게 유지한다. 프랑스 문구는 국가 전체 예방활동과 외부업체의 별도 Plan de prévention을 구분한다. 자원 기록은 조치번호별 입력이며 예산의 사전 승인이나 조치 완료로 번역하지 않는다. 단어 `revision`은 번역본이 아닌 문서 판본을 뜻한다.

기존 502개 용어·40개 양식의 완료 해시는 변경하지 않고 신규 4문구·8양식의 실제 생성 결과만 추가 검수한다. 현장 작성용 빈칸은 `verification/runtime`으로 설정하며 재사용 값이나 자동 승인으로 취급하지 않는다. 기존 저장 양식·출력본은 새 기본 양식으로 자동 변환하지 않는다.
