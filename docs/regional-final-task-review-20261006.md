# 24개 잔여 작업 조합 일괄 검수 — 2026-10-06.25

대상: JP·IT·BR·CA-QC·SA·RU × 고소·밀폐·전기·화기, 총 24조합. 기존 기본 양식 89개, 다른 국가의 작업 종결 48개, 용어 종결 567개는 수정하지 않는다. Case Study·guideline·DB·실제 계정·운영 배포는 이번 범위가 아니다.

## 이번 반영

- 작업별 추가 확인란 137개: 총 463 → 600개. 모든 확인값·사람·측정값은 현재 작업에서 입력하며 이전 작업이나 사용자가 `standard`로 바꾼 값도 새 작업·복제 시 초기화한다.
- 새 문구 13종 × 10언어. 화면 언어와 무관하게 작업 국가의 원어 역할을 유지한다. 일본 측정기록, 이탈리아 업체·발주자 역할, 브라질 작업지시서·PET 서명, 퀘벡 기록·구조 기준을 구분했다.
- 작업 14조합의 앱 확인란 범위 최종 대조. 출처 제한 3건(IT.height, BR.height, CA-QC.confined)을 새 공식 원문으로 해결했다. 아직 남은 10조합은 보완하되 종결하지 않았다.
- 러시아 원어 중 고소·밀폐 2묶음의 의미를 감독기관 원문과 대조했다. 전기 역할 묶음은 원문 확인이 충분하지 않아 남겼다. 용어 검수와 최신 법령 전체 검수는 서로 별개다.
