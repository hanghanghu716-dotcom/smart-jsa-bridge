## ③ 이번 문구 검수 범위

다음 **9개 키 × 10개 언어(90개 문자열)**를 영문 원문 의미와 대조했습니다. ko/en/de/ja/fr/it/es/ar/pt/ru 순으로 주체, 조건, 수치/단위, 예외 범위를 확인했습니다. 이는 이 문구의 번역 검수이며 국가 전체 적합성 인증이 아닙니다. 자동 테스트는 이 의미 대조를 대신하지 않습니다.

| 키 | 의미 대조 기준 |
|---|---|
| sgAnchorRegister | every shift와 교대 종료 전 인계, 적격자, each entry 최소 2년을 모든 언어에서 유지 |
| sgRopeRegister | rope access라는 조건, PE 원어, 최소 2년, 수목 예외의 근거를 요구하고 자동 면제하지 않음 |
| sgJointInspection | 평가자와 감독자 두 주체, 작업장과 주변 두 범위를 유지 |
| sgHotBasisSketch | 필요성 AND 대체방법 없음, 정확한 위치, 일련번호 통제 문서; 발급 완료값을 미리 채우지 않음 |
| sgHotEquipmentRegister | 아크/가스/안전장치의 30일/14일/12개월 대응, 59조 범위, 지난/다음 점검일 구분 |
| sgHotBreakRestart | 식사 예외를 일반 휴식으로 확대하지 않음; 환기 AND 재개 전 검사, 가연성 분위기 검사와 산소측정 구분 |
| sgHeightLawNotice | 공장 AND 추락거리 3m 초과; 그 미만도 일반 방호 가능; First Schedule 적용 확인; 만료 시 재신청 |
| sgHeightScope | PTW 적용 범위와 일반 방호 의무 구별, ‘방호가 있으면 자동 면제’라는 해석 제거 |
| sgMarineHotDetail | safety assessor/ship repair manager/fire watchman 원어 역할 유지; 일일 검토와 신규 신청 구별; 작업 후 시간 자동 지정 없음 |

검수 문자열의 SHA-256을 `regional-terminology-closures.json`에 고정합니다. 이후 문구가 바뀌면 기존 종결 기록으로 자동 통과할 수 없습니다. 보고서 확인 단계 지표의 ③ 최종 확인에 위 9개만 반영합니다.

## 계속 남는 구체적 범위

- SG 고소: 비계·사다리·지붕의 상세 대책과 로프 시스템 설계 조건, First Schedule의 실제 사업장 적용을 전체 항목별로 대조하는 최종 확인.
- SG 화기: 53–59/62–65조의 장비별 전압·감전방지기·가스기구·환기 조건 및 비상신고 세부 절차와 전체 입력란 대조. 이번 61조 기록란만으로 이 조건을 모두 충족한 것으로 표시하지 않음.
- 이탈리아 현행 통합본은 148조 열람 후 다른 조문에서 ‘articolo non trovato’가 발생해 전 조문 대조를 완료하지 못함. 기존 미해결 상태 유지.
- 퀘벡 현행 원문은 직접 접근 시 502 응답. 사우디 시행 절차, 브라질 개정·경과조치, 러시아 현행 개정 대조도 그대로 남음.

② 원문/범위 미해결 작업은 15→13개. ② 최종 항목 확인 0건은 유지. ③ 분모는 새 문구 7개 추가로 447→454개이고, 최종 확인은 0→9개입니다. 확인 단계에 동일 가중치를 두는 기존 집계 규칙을 유지하며, 실제 남은 시간의 비율로 해석하지 않습니다.
