## 완료의 범위

기존 검수 목록의 적용 조건·대책·역할·중단/재개·기록·예외를 **편집 가능한 작업별 확인란**과 대조했다. 아래 출처의 해당 범위에서 빠진 기록란을 추가했다. 입력란의 존재나 서명만으로 작업을 승인하지 않으며 법정 완성 허가서라고 표시하지 않는다. 현장 수치·측정·서명·자격 판단은 매 작업 새로 확인한다. 실제 계정 검증은 ⑤의 별도 범위다.

GB는 HSE의 Great Britain 범위이며 NI 별도 법령 검수 완료로 확장하지 않는다. US는 연방 일반산업으로 한정하고 State Plan·건설·조선·농업·특수 전력작업을 포함하지 않는다. CA는 CCOHS 일반 안내이고 연방/주별 법률의 통합 판정이 아니다. 장비 설계, 부착점 계산, 구조훈련 시행, 자격 부여, 법정 허가 발급은 이 소프트웨어 검수의 결과가 아니다.
