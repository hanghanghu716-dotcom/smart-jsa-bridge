# ②·③ 검수 목록과 집계

기준: 2026-10-05.4. 이 파일과 JSON은 scripts/regional-review-ledger.js에서 생성합니다.

대상은 작업별 서류 묶음의 **기본 양식 89개 + 관할별 작업 항목 72개**입니다. Case Study 본문·첨부 PDF, guideline 콘텐츠와 웹사이트 전체 UI는 포함하지 않습니다.

## 집계 해석

- ② 추가 조항 대조 기록: **72/72개 (100%)**. 이는 추가 대조가 있는 범위이며 전체 검수 완료율이 아닙니다. 추가 입력란은 195개입니다.
- 기초 출처 대조만 있는 작업 항목: 0개. 현행 원문·시행 또는 적용 범위가 미해결인 항목: **15개**. 아래 표의 ‘원문/범위 미해결’ 및 JSON의 remaining을 확인하세요.
- 기본 양식 89개는 기존 국가별 기초 검수 보고서에 연결됩니다. 양식별 세부 항목 종결은 별도 기록이 필요합니다.
- ③ 고정 검수 목록: 기본 문서 문구 89개, 작업별 문구 197개, 원어 역할·용어 72개 조합, 문서 명칭 89개. 각 문구는 10개 언어를 대상으로 합니다. 번역 존재율과 전문용어 검수 완료율은 구분합니다.
- 기존 보고서에는 모든 항목의 종결 기록이 없으므로 전체 완료율은 **미산정**입니다. 추가 입력란 수·번역 존재 여부만으로 완료율을 만들지 않습니다.

## 완료 기준

1. 현행 공식 출처와 업종·관할 범위를 특정합니다.
2. 적용 조건·대책·역할·중단/재개·기록·예외를 양식과 대조합니다.
3. 변경 용어를 10개 언어로 검수하고 현지 법적 역할과 일반 번역을 구분합니다.
4. 현장값 초기화·복제 독립성·출력 당시 근거 보존·국가 간 혼입 방지 시험을 통과합니다.
5. 선언한 검수 범위 안의 미해결 사항을 해소하거나 근거와 함께 범위 밖으로 명시합니다.
