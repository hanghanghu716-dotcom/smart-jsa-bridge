# 문서명·공통 작업 문구 검수 — 배치 .7

대상은 작업별 서류 묶음의 문서명 89종과 공통 작업 확인 문구다. 18개 관할·10개 문서 언어를 비교했다. Case Study·guideline 본문 및 PDF는 수정하지 않았다.

## 문서명 89종

각 관할의 원어 명칭과, 다른 언어를 선택할 때 붙는 번역 문서 유형을 함께 대조했다. 번역된 유형만으로 현지 명칭을 대체하지 않는다. 89종 × 10언어의 실제 생성 제목을 검수 기록의 해시에 고정했다. 이것은 제목의 의미·범위 검수이며 해당 양식의 법적 요건 전체 종결은 아니다.

## 공통 문구 47개와 보완

`taskSafetyText.js`의 최초 공통 묶음 47개를 10언어로 읽고 의미를 대조했다. 이전에 종결된 `sgHeightScope`는 중복으로 세지 않으며 **46개**의 기록을 추가한다.

- 미국 일반산업/건설/조선, 영국/북아일랜드, 호주 주·준주, 캐나다 연방·주, 해양 분야 한계, 정전/활선의 범위 구분 유지. 아랍어 호주 안내에 빠진 준주를 보완했다.
- 한국어·일본어 담당자 확인에 역량을 명시했다. 교육 이수나 자격증만으로 현장 작업권한을 부여하지 않는다.
- 프랑스어 검전기 명칭을 무전압 확인기로 구체화했다.
- 프랑스어·이탈리아어·스페인어·포르투갈어·러시아어의 인접 부분 보호에 빠진 **충전 상태**를 명시했다. 일반 인접 부품으로 오독되지 않게 했다.
- 이탈리아어·스페인어·포르투갈어의 역류 방지를 **화염의 역화 방지**로 구체화했다.
- 영어·한국어·이탈리아어·스페인어·포르투갈어 출입기록은 전원 퇴장 확인을 명시했다. 일반 최종 확인이나 작업 승인과 구분했다.
- 프랑스어·이탈리아어·스페인어·포르투갈어·러시아어의 측정기 기록에는 **식별정보**를 명시했다.
- 그 외 고소 회피, 추락 방지/제동, 취약면, 구조, 산소 등 대기 측정, 에너지 차단, 환기, 복전, 화재감시, 가연물, 중지·재허가와 안내 문구는 조건부 적용과 작업별 신규 입력 의미를 유지한다.

## ② 싱가포르 위험성평가 보완

[MOM 위험관리 안내](https://www.mom.gov.sg/workplace-safety-and-health/safety-and-health-management-systems/risk-management)에 따라 일상/비일상 작업(준비·고장진단·시운전·정비)과 평가팀 참여, 영향받는 관계자에게 위험·대책을 전달한 기록을 추가했다. 기존 작업자 참여 항목을 도급업체 등 이해관계자까지 구체화한 것이다.

[Risk Management Regulations 제5조](https://sso.agc.gov.sg/SL/WSHA2006-RG8?ProvIds=pr5-&ValidDate=20250101)의 평가·실행 대책/안전절차 기록 최소 3년 보존을 관리하는 필드를 추가했다. 재평가 주기와 기록 보존 기간을 섞지 않는다. 이 필드는 사용자가 보존 체계를 기록하는 칸이며, 서비스가 자동으로 법정 보관을 보장하거나 3년 후 삭제하는 기능이 아니다. 새 3개 문구도 10언어를 대조했다.

해당 조항의 공식 색인 본문과 MOM 안내는 확보했지만, SSO 전체 조문 및 다른 조항 직접 열람은 접근 제한이 있었다. 이 보완을 SG 위험성평가의 모든 세부 요건 종결로 올리지 않았다. ②의 전체 양식 최종 검수와 미해결 13개 작업 조합은 계속 남는다.

새 필드는 SG 위험성평가에만 들어가며 실제 확인값은 매 작업마다 빈 값으로 시작한다. 기존 저장 양식과 출력본을 새 버전으로 덮어쓰지 않는다. 원어 제목 변경도 신규 생성 문서에만 적용한다.

## 완료 기록 기준

이번 용어 기록 추가는 제목 89 + 공통 문구 46 + 신규 평가 문구 3 = **138개**다. 이전 111개를 합해 **249개**다. 용어 대상은 새 문구 3개 추가로 468→471개가 됐다. 모든 완료 기록은 의미 대조 후 실제 생성 문자열의 해시를 고정한 것이다. 자동 생성·빈 값 검사만으로 의미 검수를 완료 처리하지 않는다.

검수 스크립트는 현지 문서명과 번역 접두어가 바뀌면 제목 완료 기록을 무효화한다. 이전 기본 문구·작업 문구의 해시 검사도 유지한다. ②와 ③의 완료 기준을 섞지 않는다.
